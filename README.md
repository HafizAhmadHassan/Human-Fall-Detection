# Human Fall Detection

An AI course final project on **detecting human falls**, developed as part of the Master's in Bioinformatics coursework.

## Overview

The project applies computer vision / deep learning techniques to recognise falls from visual or sensor data. It includes a full Python implementation, a written project report, and a poster summarising the approach and results.

## Repository Structure

```
├── code/          # Python implementation (models, training, inference)
├── report/        # Written project report
├── poster/        # Project poster
└── docs/          # Supporting documentation
```

## Features

- Fall detection pipeline (data → model → prediction)
- Training and evaluation scripts
- Accompanying report and poster

## Tech Stack

Python, deep learning / computer vision, Jupyter Notebooks.

Completed university project.
